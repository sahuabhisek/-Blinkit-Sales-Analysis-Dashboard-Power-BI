# 🛒 Blinkit Sales Analysis Dashboard – Power BI

## 📌 Project Overview

This project focuses on analyzing Blinkit's sales performance using Microsoft Power BI.

The dashboard provides an interactive view of sales trends, outlet performance, product categories, fat content and outlet locations.

The main objective is to convert sales data into meaningful business insights that support better decision-making.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Compare sales across different outlet types.
- Understand product category performance.
- Analyze Low Fat and Regular product sales.
- Compare outlet performance across different location tiers.
- Monitor important business KPIs.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Modeling
- Data Visualization
- Interactive Slicers and Filters

## 📈 Dashboard Analysis

### 1. Sales by Outlet Establishment Year
Analyzes sales trends based on outlet establishment years.

### 2. Fat Content Analysis
Compares sales between Low Fat and Regular products.

### 3. Item Type Analysis
Evaluates sales contribution from different product categories such as Fruits and Vegetables, Snack Foods, Household, Dairy and Frozen Foods.

### 4. Fat Content by Outlet Location
Compares product fat content sales across different outlet location tiers.

### 5. Outlet Location Analysis
Analyzes outlet performance across Tier 1, Tier 2 and Tier 3 locations.

### 6. Outlet Type Analysis
Compares Total Sales, Average Rating, Average Sales and Average Item Weight across outlet types.

## 🔍 Key Business Insights

- Overall sales are approximately 1.20 million.
- Regular Fat products contribute approximately 776.32K in sales.
- Low Fat products contribute approximately 425.36K in sales.
- Supermarket Type 1 has the highest sales among the displayed outlet types.
- The dashboard highlights a sales peak around the 2018 establishment-year point.
- The average rating across the dashboard is 3.92.

## 🎛️ Interactive Features

The dashboard includes interactive slicers for:

- Outlet Location Type
- Outlet Size
- Outlet Type

Users can filter the dashboard to explore different sales segments.
